01. ARCHIVAL_ENTOMOLOGY_OVERVIEW

Insect Vault is an archival procedural entomology synthesis engine and vector anatomical repository modeled after 19th-century cabinet-of-curiosities pin-mounted field studies. Drawing upon the classical taxonomic methodologies of Carl Linnaeus's Systema Naturae (1758) and Dru Drury's Illustrations of Natural History (1770), the engine procedurally synthesizes insect specimens across three seminal orders: Coleoptera (beetles with sclerotized elytra and puncture striae), Lepidoptera (butterflies and moths with radial wing venation and discal cells), and Odonata (dragonflies with dense reticulated Voronoi wing venation and pterostigma cells).

02. PROCEDURAL_ANATOMY_PIPELINE

By injecting descriptive narrative strings into the system, the engine hashes the input to establish anatomical morphology, head mouthparts (pincer mandibles, proboscis), antennae typology (lamellate, bipectinate plumose, clavate), thoracic chitin sclerites, articulated spinose legs, and orders of wing venation. Every specimen is an immutable archival record deterministically reproducible via its accession identifier (e.g. INV-CO-0048A2) and cryptographic pointer hash.

03. ARCHIVAL_EXPORT_PROTOCOL

Specimens can be exported as clean standalone SVG vector documents or 300 DPI high-resolution PNG plates conforming to the Swiss-Archival design standards. Each exported plate integrates archival double drafting borders, a 5mm Micro-Metric Caliper Rule (SCALE 10:1), an Archival Cinnabar Vermilion Seal Chop (朱砂印章 · 虫豸典藏), an enameled brass entomological mounting pin, and an authentic Hershey single-stroke cursive Latin binomen.

04. EMBED_INTEGRATION_PROTOCOL

Insect Vault functions as an embeddable micro-service. Appending the mode=embed query parameter reduces the UI to an isolated specimen view optimized for responsive iframes. Host applications can dynamically command the synthesis engine in real-time via the bidirectional postMessage protocol.

05. PROGRAMMATIC_ARCHIVAL_ACCESS

The underlying engine exposes pure zero-dependency JavaScript access via window.InsectDraw. Curators and developers can synthesize specimens, query telemetry metrics, and render vector plates programmatically in Node.js or browser environments.
