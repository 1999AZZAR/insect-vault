01. EXECUTIVE_ARCHITECTURE_OVERVIEW

Insect Vault is an archival procedural synthesis engine generating 19th-century cabinet-of-curiosities pin-mounted entomological field studies. Grounded in the taxonomical traditions of Carl Linnaeus's Systema Naturae (1758) and Dru Drury's Illustrations of Natural History (1770), the engine procedurally synthesizes three foundational insect orders: Coleoptera (beetles with sclerotized elytra, suture lines, and puncture striae), Lepidoptera (butterflies and moths with radial wing veins and discal cells), and Odonata (dragonflies with dense reticulated Voronoi crossveins and pterostigma cells).

Every synthesized specimen is a 100% deterministic SVG vector plate that features Swiss-Archival dual drafting borders, a 5mm Micro-Metric Caliper Rule (SCALE 10:1), an Archival Cinnabar Vermilion Seal Chop (朱砂印章 · 虫豸典藏), a realistic enameled brass entomological mounting pin at the mesothoracic disc, and single-stroke engraved Hershey cursive Latin binomen lettering.

02. PROCEDURAL_SYNTHESIS_PIPELINE

The synthesis engine operates through five sequential anatomical phases:

  1. Narrative Seed Hashing: Computes a 32-bit FNV-1a hash from the narrative sequence to seed the isolated Mulberry32 PRNG deterministically.
  2. Taxonomic Classification & Binomen Derivation: Selects order (Coleoptera, Lepidoptera, Odonata), resolves genus, species epithet, family, and accession sequence identifier (e.g. INV-CO-0048A2).
  3. Morphological Sclerite Construction: Synthesizes head capsule, compound eye ommatidia facets, antennae morphology (lamellate, bipectinate plumose, clavate, setaceous), pronotal thoracic shield, scutellum, and 8 to 10 abdominal urotergites.
  4. Wing System & Reticulation Generation: Procedurally constructs wing contours and venation. For Coleoptera: hardened elytra with 12 parallel longitudinal puncture striae. For Lepidoptera: broad forewings and hindwings with discal cells, radial veins, and submarginal lunules. For Odonata: 4 vitreous elongated wings with Costa, nodus notch, pterostigma cells, and dense Voronoi-like reticulation crossveins.
  5. Archival Cabinet Presentation: Injects Swiss-Archival dual drafting borders (outer 1.0pt, inner 0.5pt), 5mm caliper rule (SCALE 10:1), central brass mounting pin head, Cinnabar seal chop (虫豸典藏), and cursive engraved Hershey vector binomen.

03. JAVASCRIPT_API_REFERENCE

Insect Vault exposes a zero-dependency UMD module via window.InsectDraw:

InsectDraw.synthesize(seedInput, options)

Synthesizes a procedural entomological specimen and returns all anatomical parameters, taxon classification, and telemetry metrics.

const specimen = InsectDraw.synthesize("Dynastes hercules Cabinet Holotype", {
  width: 1200,
  height: 800,
  palette: "curio" // "curio" | "scarab" | "cyanotype" | "amber" | "malachite"
});

console.log(specimen.accessionId); // e.g. "INV-CO-0048A2"
console.log(specimen.binomen); // e.g. "Dynastes hercules"
console.log(specimen.metrics.wingspanStr); // e.g. "78.4 mm // 42.1 mm Body"

InsectDraw.generateSvgPlate(data, options)

Generates a complete standalone SVG document complete with archival borders, caliper rule, mounting pin, and vermilion seal chop.

const svgString = InsectDraw.generateSvgPlate(specimen, {
  width: 1200,
  height: 800,
  palette: "scarab"
});
// Save to file or inject into DOM

InsectDraw.renderToCanvas(data, canvas, options)

Renders the specimen onto an HTML5 canvas at any target resolution for high-resolution 300 DPI PNG export.

const canvas = document.createElement('canvas');
canvas.width = 2400;
canvas.height = 2400;
await InsectDraw.renderToCanvas(specimen, canvas, {
  palette: "curio"
});
const pngDataUrl = canvas.toDataURL('image/png');

04. EMBED_INTEGRATION_PROTOCOL

Add mode=embed to any Insect Vault URL to enable distraction-free specimen rendering optimized for responsive iframes: 

<iframe 
  src="https://insect-vault.glassgallery.my.id/?id=INV-CO-0048A2&palette=curio&w=1&h=1&mode=embed" 
  width="100%" 
  height="600" 
  frameborder="0" 
  style="border:1px solid #DDD5C5; background:#EFE9DC;">
</iframe>

Dynamic postMessage Controller

// Send new entomology parameters to embedded iframe
const iframe = document.querySelector('iframe');
iframe.contentWindow.postMessage({
  seed: "Anax imperator Vitreous Dragonfly Wingspan",
  palette: "cyanotype",
  w: 16,
  h: 9
}, "*");
